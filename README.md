
# Exploratory Data Analysis and Statistical Analysis of the Iris Dataset Using Python

## 📌 Overview
This project explores the Iris dataset using Python, focusing on exploratory data analysis, descriptive statistics, and data visualization.

## 🎯 Objectives
- Explore and understand the dataset.
- Calculate descriptive statistical measures.
- Visualize data distributions and relationships.
- Compare measurements across Iris species.

## 📊 Dataset
The dataset contains 150 observations of three Iris species:
- Setosa
- Versicolor
- Virginica

**Features:**
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 🔍 Analysis Performed
- Data exploration and inspection
- Descriptive statistical analysis
- Data visualization
- Species-wise comparison
- Correlation analysis

## 📈 Results
The analysis helps identify patterns, compare flower measurements, and understand relationships between variables.

Gained practical experience in Python programming, statistical analysis, exploratory data analysis, and data visualization.
